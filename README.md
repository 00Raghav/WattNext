# WattNext

## Project Title

Smart Meter Load Profiling and Consumer Energy Consumption Clustering

## Project Description

WattNext is a machine learning project that analyzes
smart meter electricity consumption data and groups
consumers with similar energy usage patterns.

## Objectives

- Explore smart meter data
- Analyze electricity consumption patterns
- Create consumer-level features
- Apply K-Means clustering
- Visualize consumer groups
- Build an interactive Streamlit dashboard
- Deploy the application online

## Technology Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit
- Git and GitHub

## Project Status

Currently working on dataset exploration.

## Repository Structure

- `data/`: Dataset files
- `notebooks/`: Data analysis notebooks
- `src/`: Reusable Python code
- `docs/`: Documentation
- `app.py`: Streamlit application
